# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/238d26de-4714-463b-bde1-d7c512df601d

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## Firebase Hosting

Firebase Hosting is the canonical production frontend for this repo. The project is configured in [.firebaserc](.firebaserc) as `novembercubes-1498042979328`, and `firebase.json` deploys the Vite build output from `dist`.

Deploy the frontend with:

```bash
npm run build
firebase deploy --only hosting
```

The app and Cloud Functions are configured to use Firestore database `ai-studio-238d26de-4714-463b-bde1-d7c512df601d`. Local development is only a local preview of the same Firebase-backed app unless emulator wiring is added explicitly. The Cloud Run URL generated by AI Studio is a separate hosted copy and should not be treated as the source of truth unless it is intentionally redeployed alongside Firebase Hosting.
